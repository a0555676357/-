# نظام الصقر المحاسبي

برنامج محاسبي متكامل مبني باستخدام **C# / .NET 8 Windows Forms**.

## تشغيل المشروع

1. افتح `GTSErpSystem.sln` أو `GTSErpSystem.csproj` باستخدام Visual Studio 2022 أو أحدث.
2. تأكد من تثبيت .NET 8 SDK وWindows Desktop Runtime.
3. أنشئ قاعدة بيانات SQL Server باسم `AlSaqarAccounting` أو عدّل سلسلة الاتصال في `appsettings.json`.
4. شغّل المشروع. عند أول تشغيل سيطلب النظام إنشاء المستخدم الأول إذا لم يجد جدول `User_Login`.

## تنظيم المشروع

- `UI/`: النوافذ العامة والتنقل وتسجيل الدخول.
- `Models/`: نماذج البيانات.
- `Data/`: طبقة الوصول إلى البيانات والاستعلامات.
- `Services/`: الخدمات المشتركة مثل المصادقة.
- `GTSErpSystem.sln`: ملف الحل الرئيسي.

## التنقل بين النوافذ

تُقرأ قائمة النوافذ من `UI/form-catalog.json` وتُجمع حسب الوحدة داخل `MainForm`.
عند اختيار نافذة:

- يُفتح النموذج الفعلي تلقائيًا إذا كان موجودًا في التجميعة.
- إذا لم يكن النموذج موجودًا لكن له `entity`، تُفتح شاشة تصفح عامة للكيان.
- إذا لم يتوفر أي منهما، تظهر رسالة واضحة بدل حدوث خطأ صامت.

## ملاحظات أمنية

لا تضع كلمات مرور أو مفاتيح حقيقية داخل `appsettings.json` في مستودع عام. استخدم User Secrets أو متغيرات البيئة في بيئة الإنتاج.
